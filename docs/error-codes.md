# CampusPass 错误码

成功响应统一使用 `code = 0`。失败响应同时使用合适的 HTTP 状态码和下列业务错误码：

| 错误码 | HTTP 状态 | 含义 |
| --- | --- | --- |
| 40000 | 400 | 请求参数有误 |
| 40001 | 400 | 参数校验失败 |
| 40100 | 401 | 未登录或登录状态失效 |
| 40101 | 401 | 账号或凭证有误 |
| 40102 | 401 | Token 或认证请求头无效 |
| 40103 | 401 | 账号已被禁用 |
| 40104 | 401 | 验证码无效 |
| 40300 | 403 | 无权执行操作 |
| 40301 | 403 | 不是资源所有者 |
| 40302 | 403 | 不允许执行该管理员操作 |
| 40400 | 404 | 用户不存在 |
| 40401 | 404 | 活动不存在 |
| 40402 | 404 | 请求记录不存在或暂不可见 |
| 40900 | 409 | 唯一资源冲突，例如用户名、手机号或学号重复 |
| 40901 | 409 | 活动状态冲突 |
| 40902 | 409 | 不在报名时间内 |
| 40903 | 409 | 重复报名 |
| 40904 | 409 | 当前没有有效报名 |
| 40905 | 409 | 当前不在候补中 |
| 40906 | 409 | 活动容量冲突 |
| 40907 | 409 | 数据状态已变化 |
| 42900 | 429 | 请求过于频繁 |
| 50000 | 500 | 未分类的服务端异常 |
| 50001 | 500 | 数据操作失败 |
| 50002 | 500 | 缓存操作失败 |
| 50003 | 500 | 消息处理失败 |
| 50004 | 500 | 数据状态不一致 |
| 50300 | 503 | 服务繁忙，可稍后重试 |
| 50301 | 503 | 请求被中断，可稍后重试 |

响应示例：

```json
{
  "code": 40903,
  "message": "您已经报名过了",
  "data": null
}
```

前端应主要依据 `code` 处理业务分支，`message` 用于展示具体提示，HTTP 状态用于表示错误所属的大类。
