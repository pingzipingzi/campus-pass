| 项目 | 内容 |
| --- | --- |
| 测试日期 | 2026-10-11 |
| 代码基线 | `main`（2026-10-11 本地版本） |

| 后端地址 | `http://localhost:8080` |

本报告验证报名链路在并发情况下是否会产生重复有效报名、库存超卖或报名与候补状态并存。测试规模较小，结论用于业务正确性验证，不代表生产环境的容量上限。

## 场景一：同一用户并发重复报名

### 测试方法

- JMeter 脚本：`tests/jmeter/registration-concurrency.jmx`；
- 使用同一个用户的 Token 启动 20 个并发线程；
- 20 个线程同时请求同一个活动的报名接口；
- 断言只接受 HTTP `200` 或表示重复报名的 HTTP `409`；
- 消息消费完成后核对报名表、候补表和活动剩余库存。

### HTTP 与 JMeter 结果

| 指标 | 结果 |
| --- | ---: |
| 请求总数 | 20 |
| HTTP 200 | 1 |
| HTTP 409 | 19 |
| 其他 HTTP 状态 | 0 |
| 平均响应时间 | 20 ms |
| 最小响应时间 | 13 ms |
| 最大响应时间 | 54 ms |
| 标准差 | 11.19 ms |
| 吞吐量 | 20.81 次/秒 |
| JMeter 错误率 | 0% |
| P95 | 本次汇总报告未单独采集 |

JMeter 错误率为 0%，是因为测试断言将一次正常受理和其余重复报名冲突都视为符合预期。HTTP `409` 表示重复请求被业务规则正确拒绝，不代表服务异常。

### 一致性核对

- 同一用户与同一活动只存在一条有效报名或候补关系；
- 没有重复有效报名记录；
- 没有同时处于报名成功和候补中的记录；
- Redis 报名标记与数据库最终状态一致；
- RabbitMQ 队列处理完成，无异常积压。

### 结论

同一用户的重复并发请求被幂等校验和数据库约束正确拦截，没有产生重复报名数据。

## 场景二：20 个不同用户竞争 5 个名额

### 测试方法

- JMeter 脚本：`tests/jmeter/registration-multi-user.jmx`；
- 活动 ID：`46`；
- 活动总名额：5；
- 从 `accounts.csv` 读取 20 个不同测试账号；
- 每个线程先登录并提取自己的 JWT；
- 同步等待全部账号登录完成后，同时发起报名；
- 等待 RabbitMQ 的 Ready 和 Unacked 均归零，再核对数据库与 Redis。

### JMeter 结果

| 请求 | 样本数 | 平均 | 最小 | 最大 | 标准差 | 错误率 | 吞吐量 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 登录并获取 Token | 20 | 354 ms | 246 ms | 426 ms | 52.00 ms | 0% | 46.40 次/秒 |
| 并发报名活动 | 20 | 40 ms | 29 ms | 75 ms | 9.88 ms | 0% | 263.16 次/秒 |
| 总体 | 40 | 197 ms | 29 ms | 426 ms | 161.28 ms | 0% | 78.90 次/秒 |

本次使用的汇总报告没有单独输出 P95，因此不对 P95 作推算或补填。报名吞吐量来自 20 个请求的短时突发测试，只适合描述本次运行结果。

### 最终一致性结果

| 检查项 | 结果 |
| --- | ---: |
| 有效报名数 | 5 |
| 候补中人数 | 15 |
| 剩余名额 | 0 |
| 是否超卖 | 否 |
| 是否存在重复有效报名 | 否 |
| 是否同时存在有效报名和候补 | 否 |
| RabbitMQ 是否处理完成 | 是 |

### 结论

20 个用户同时竞争 5 个名额时，系统最终保留 5 条有效报名记录，其余 15 个用户进入候补队列，剩余库存为 0。Redis 预扣库存、RabbitMQ 异步消费和 MySQL 最终数据保持一致，没有出现超卖。

## 验证范围与限制

本次测试证明了当前实现对 20 并发场景的业务一致性处理符合预期，同时覆盖了重复请求、库存竞争和候补分流。测试在单机开发环境完成，尚未覆盖以下内容：

- 多实例部署下的长时间稳定性和容量上限；
- 网络延迟、RabbitMQ 宕机或 Redis 故障注入；
- 数百或数千并发下的资源利用率与性能拐点；
- 独立测试环境中的 P90、P95 和 P99 长时间统计。

这些限制不影响本次业务正确性结论，但不能将本报告中的吞吐量直接作为生产性能指标。
